# Context Compression Ablation

This folder contains a compression-focused ablation table built from completed
SciFact and HotpotQA runs.

Unlike Table B, this table is not only about the internal components of Safe
Adaptive Context. It compares full context and compact evidence variants across
different methods and completed final runs.

## Files

- `context_compression_ablation.csv`: CSV version of the ablation table
- `context_compression_ablation.md`: Markdown version of the ablation table
